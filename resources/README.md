# Resources

`fixtures/legacy-working-v1.tsv` contains synthetic working-file records generated by iiSharedCanvas Native 0.34.1. The data covers a 3×2 bitmap, including transparent RGB, and supplies the storage-v1 migration regression tests. Each line is tab-separated `kind`, `id`, `position`, `dataHex`, and `sha256Hex`. The fixture is source-controlled input and is installed with the Native package; tests generate disposable databases separately in the build directory.

`fixtures/growing-stroke-v1.tsv` is a storage-v1 infinite canvas with a hidden negative-coordinate chunk, generated by the frozen Native 0.34.0 writer in `tests/legacy-growing-writer/`. It uses the same record format and supports expansion, migration, undo, and redo regressions without modifying the fixture.
