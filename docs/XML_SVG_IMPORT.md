# iiXml을 조합한 제한적 SVG 가져오기

`example/XmlSvgDecoder.h/.cpp`는 애플리케이션이 iiSharedCanvas의 네이티브
벡터 모델, `iiXml::Native`와 `iiCompression::iiCompression`을 조합하는 예시다.
`decodeCanvasSvg`는 메모리에
있는 SVG 바이트, 호출자가 선택한 에셋 ID와 `MediaLimits`를 받아 독립적인
`VectorAsset`을 반환한다. 파일 읽기, 문서 삽입과 저장은 호출자가 맡는다.
캔버스 라이브러리가 이 두 SDK를 직접 찾거나 링크하지는 않는다.
이 어댑터는 저장소의 예시 소스이며 설치된 캔버스 라이브러리의 함수가 아니다.
애플리케이션이 예시를 빌드하거나 자체 구현을 제공한다.
두 예시의 숫자 파싱은 표준 라이브러리의 부동소수점 `from_chars` 지원을
필요로 한다. 여기서의 macOS 실행 검증은 현재 시스템에 한정되며 이전 macOS
배포 대상이나 다른 플랫폼에서의 실행을 보장하지 않는다.

이 예시는 네이티브 `encodeSvg`가 내보내는 SVG와 gzip SVGZ의 경로, 뷰포트,
단색 채우기·획과 알파를 편집 가능한 값으로 되돌린다. 경로 명령은 대문자
`M`, `L`, `Q`, `C`, `Z`, 채우기는 even-odd, 획의 끝과 연결은 round이다.
원점이 0이고 크기가 출력 뷰포트와 같은 `viewBox`만 지원한다. 입력 식별자는
비어 있지 않은 UTF-8이어야 하며 NUL을 포함할 수 없다.
캔버스의 8비트 알파로 표현할 수 없는 불투명도는 반올림하여 내용을 바꾸지 않고
거부한다. 자체 내보내기의 알파 값 256단계는 모두 복원할 수 있다.

변환, 그룹, 텍스트, 도형 요소, 그라디언트, 비정규 경로 명령과
외부 참조 등 다른 SVG 표현은 지원하지 않으며 일부 경로만 반환하지 않는다.
DTD와 처리 명령도 거부한다. 따라서 이 예시는 기존 Qt SVG 가져오기를 완전히
대체하지 않는다. SVGZ는 완전한 gzip 멤버 하나만 허용하며 잘림·체크섬 오류·
뒤따르는 바이트와 이어 붙인 멤버를 거부한다. 압축 입력은 `maxInputBytes`,
압축 해제된 XML은 `maxDecodedBytes`를 따른다. 입력 바이트·뷰포트 픽셀·XML
깊이·경로 명령과 논리적 벡터 저장량을 제한한다. XML 파서와 검증 과정의 임시
버퍼 및 할당자 오버헤드는
`maxDecodedBytes`를 포함한 프로세스 전체 메모리 상한이 아니다.
XML 요소당 속성은 최대 16개이며 이벤트 수는 `2 * maxVectorCommands + 32`로
제한한다. 일반 SVG의 개별 XML 텍스트 항목은 입력과 디코딩 바이트 한도 중
작은 값을, SVGZ의 해제된 XML 텍스트 항목은 디코딩 바이트 한도를 따른다.

`tests/native-svg-consumer`는 Qt 검색을 끄고 각각 스테이징된
`iiSharedCanvasNative`, `iiXmlNative`, `iiCompression` 패키지를 조합한다.
출력 SVG/SVGZ를 다시 읽어
편집 가능한 명령과 렌더된 픽셀·알파를 비교하고, 지원하지 않는 요소, 잘못된
수치, 외부 엔티티, 유효하지 않은 ID와 자원 한도를 검사한다.

## 명시적인 SVG 비트맵 가져오기

`example/GuiSvgRasterizer.h/.cpp`는 애플리케이션이 iiXml, iiCompression,
iiGUI 및 네이티브 캔버스를 조합하는 별도 예시다. `rasterizeGuiSvg`는
메모리의 SVG 또는 SVGZ와 출력 크기를 받아 단일 `RasterAsset`을 만든다.
결과에는 경로와 그라디언트가 픽셀로 변환되어 편집 가능한 벡터 정보가
남지 않는다는 경고가 포함된다. 파일 읽기와 저장은 호출자의 책임이다.
이 예시도 설치된 캔버스 라이브러리의 함수가 아니며 PDF는 처리하지 않는다.
픽셀은 비선행 알파 ARGB이며, 래스터화 과정의 8비트 반올림과 경계
안티앨리어싱에 따라 원래 부동소수점 불투명도와 정확히 같지는 않을 수 있다.

입력은 명시적 양수 `width`·`height`를 가진 SVG, 그룹, `rect`, `path`,
`defs`의 `linearGradient`와 `stop`으로 제한한다. 경로는 M/L/H/V/Q/T/C/S/Z의
대문자·소문자 명령과 반복을 허용한다. 단색 및 로컬 선형 그라디언트 채우기와
획, even-odd·nonzero 채우기, 제한된 불투명도 및 획 속성을 처리한다.
단색은 `#RGB`, `#RRGGBB`와 코드에 명시된 기본 색 이름만 허용한다.
좌표는 유한해야 하며 절대값이 10억을 넘으면 거부한다. 변환, 원호, 다른
도형, 스타일시트, 텍스트, 이미지, 클립, 마스크, 필터, 애니메이션, 외부
참조와 알려지지 않은 요소·속성은 거부한다. 없는 그라디언트 참조도 거부한다.
지원 범위 밖의 일반 SVG와 PDF 페이지의 기존 Qt 래스터화 기능을 대체했다고
간주하지 않는다.

압축 입력은 `maxInputBytes`, SVGZ 확장 결과는 `maxDecodedBytes`를 따른다.
iiGUI는 확장된 SVG 입력을 1 MiB, 출력 한 변을 8192 픽셀, 출력 전체를
64 Mi 픽셀로 제한한다. SVGZ는 압축 해제 중에도 1 MiB 한도를 적용한다.
호출자의 픽셀·프레임·디코딩 바이트·XML 깊이·경로
명령 한도도 적용한다. XML 요소당 속성은 최대 16개, 이벤트는 최대 100,000개다.
일반 SVG의 개별 텍스트 항목 한도는 입력과 디코딩 한도 중 작은 값이고 SVGZ는
디코딩 한도다. 디코딩 바이트 한도는 결과 픽셀이나 압축 해제 데이터의 논리적
크기이며 XML·래스터화 임시 버퍼와 할당자 오버헤드를 포함한 전체 프로세스
메모리 상한이 아니다. 실패하면 부분 픽셀을 반환하지 않는다.

`tests/native-svg-raster-consumer`는 Qt 검색을 끄고 설치 패키지를 조합해
그라디언트, 직선 경로, 투명도, SVGZ 픽셀과 거부·한도 조건을 검증한다.
