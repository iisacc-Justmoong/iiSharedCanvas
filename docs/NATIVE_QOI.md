# 네이티브 QOI 비트맵 계약

Qt 경로의 확장 비트맵 기능을 유지하기 위해 네이티브 비트맵 코덱은
[QOI 1.0](https://qoiformat.org/qoi-specification.pdf)을 메모리에서 읽고 쓴다.
ARGB 픽셀과 투명 픽셀의 RGB를 보존하며 별도 프로세스나 전역 코덱 상태를 쓰지
않는다. `extendedCodecs`가 꺼져 있으면 QOI를 선택하지 않고, 형식 목록의
`includeExtended=false`에도 표시하지 않는다.

입력·디코딩 픽셀·출력 크기는 기존 `MediaLimits`를 따른다. 헤더와 채널 수,
색 공간 표식, 청크 길이, 반복 횟수 및 최종 마커가 유효하지 않으면 부분 결과를
반환하지 않는다. 색 공간 표식이 선형인 입력은 픽셀 값을 바꾸지 않고 경고한다.
QOI는 텍스트를 저장하지 않으므로 텍스트를 함께 내보내면 경고한다.

이 기능은 QOI에 한정되며 다른 확장 형식의 네이티브 동등성을 의미하지 않는다.
