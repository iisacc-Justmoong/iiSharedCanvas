# iiGUI를 조합한 프레임 이미지 예시

`example/GuiFramePresenter.h/.cpp`는 애플리케이션에서 네이티브 캔버스의
`FrameRenderResult`와 iiGUI의 `RasterImage`를 조합하는 예시다. 설치된 캔버스
라이브러리의 함수가 아니며, 애플리케이션이 이 예시를 빌드하거나 같은 경계를
자체 구현한다. 캔버스 모듈에 iiGUI를 직접 링크하지 않는다.

`toGuiCanvasFrame`은 성공한 프레임의 원점과 픽셀을 받아 분리된 불변 GUI 이미지와
원점을 반환한다. 캔버스의 비선행 알파 ARGB32를 iiGUI의 비선행 알파 RGBA8로
변환하며 알파가 0인 픽셀의 RGB 바이트도 보존한다. 소스 프레임과 문서를 수정하지
않고, 반환 후 원본이 변해도 GUI 이미지는 독립적이다. 실패한 렌더, 유효하지 않은
크기나 픽셀 수, 예산 초과는 이미지를 반환하지 않는다.

기본 한도는 iiGUI의 16 Mi 픽셀이고 호출자가 최대 64 Mi 픽셀을 명시적으로
허용할 수 있다. 한 변은 최대 8192 픽셀이다. 입력 프레임의 저장 공간과 별도로
RGBA 이미지 버퍼가 필요하며, 이 한도는 프로세스 전체 메모리 한도가 아니다.
프레임 원점은 보존하지만 축소된 영역의 문서 좌표 변환은 추론하지 않는다.
애플리케이션은 요청한 영역과 출력 크기를 함께 보관해 표시 위치와 입력 좌표를
계산해야 한다.

이미지를 위젯에 설정하고 주 스레드로 결과를 전달하는 일, 화면 갱신, 확대·이동,
입력·필압, 접근성 및 장치별 실제 동작은 호출자가 맡는다. 이 예시는 프레임 픽셀의
전달 경계이며 Qt Quick `CanvasItem` 또는 `BitmapItem` 전체를 대체하지 않는다.
화면의 샘플링과 합성은 iiGUI의 표시 정책을 따른다.

`tests/native-svg-raster-consumer`의 독립 설치 소비자는 Qt 검색을 끄고 직접 만든
ARGB 픽셀과 실제 캔버스 렌더 결과, 원점, 알파, 소스 분리, 오류 및 크기 한도를
검증한다. 이 검사는 실제 OS 창이나 펜 장치의 런타임 검증이 아니다.
