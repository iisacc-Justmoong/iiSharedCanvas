# 에이전트 문서 투영 스키마

`agent-document.schema.json`은 사람용 Markdown의 원문 블록, 줄 범위, 해시 및
탐색 색인을 담는 구조를 정의한다. Markdown이 원본이며 JSON의 블록을 순서대로
이어 붙였을 때 원문과 같아야 한다. 색인의 원문 해시와 각 JSON의 해시도 같아야 한다.

기본 생성기는 `workspace-docs`이다. 해당 도구를 사용할 수 없을 때 동일한
무손실 블록 형식으로 직접 투영한 문서는 생성기를 `codex`로 기록할 수 있다.
이 값은 투영을 만든 도구를 나타내며, 대체 도구 사용 사실을 감추지 않는다.
표준 생성기를 다시 사용할 수 있게 되면 그 결과로 투영을 갱신할 수 있다.
