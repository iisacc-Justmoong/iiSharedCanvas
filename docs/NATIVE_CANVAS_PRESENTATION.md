# iiGUI 편집 캔버스 변환 계약

iiSharedCanvas의 네이티브 렌더 결과와 iiGUI의 `NativeEditorCanvas`를 조합할 때,
호출자는 렌더할 문서 영역과 출력 픽셀, 현재 iiGUI 조회 값을 명시적으로 전달한다.
구성 시 `IISHAREDCANVAS_BUILD_QT_API=OFF`와
`IISHAREDCANVAS_BUILD_GUI_ADAPTER=ON`을 지정한다. 설치 소비자는
`find_package(iiSharedCanvasGui 0.40 CONFIG REQUIRED)`와
`iiSharedCanvas::Gui` 타깃을 사용한다. iiGUI의 설치 의존성도 제공해야 한다.
화면 변환기는 이동·확대·회전·반전을 반영한 분리된 불변 그리기 스냅샷을 반환한다.
영역 밖은 투명하며 원본 픽셀과 문서는 변경되지 않는다. 픽셀 예산을 초과하거나
좌표와 프레임이 유효하지 않으면 결과를 게시하지 않는다. 프레임의 리비전과 비동기
결과 순서는 호출자가 관리한다.

입력 변환기는 iiGUI의 시작·이동·종료·취소·호버를 iiPaintEngine 입력 값으로 옮긴다.
문서 좌표, 펜 압력·기울기·회전·시간, 장치 종류와 원래 버튼 상태를 보존한다.
iiGUI의 기울기 각도는 -90~90도를 iiPaintEngine의 -1~1로 정규화하고 회전 각도는
도에서 라디안으로 변환한다.
스크롤은 별도 값으로 반환하여 호출자가 확대·이동 정책을 결정한다. 변환기는
문서나 편집기를 소유하거나 실행하지 않는다. 호출자는 입력 및 문서 수명과 실행
순서를 관리한다. iiGUI는 현재 눌린 버튼만 제공하므로 놓인 버튼은 추측하지 않고,
가운데·보조 버튼을 기본 브러시 버튼과 구분한다.

캔버스 입력 라우터는 외부가 제공한 이전 제스처 상태, 도구·선택 상태, 현재
뷰포트와 변환된 입력 하나를 받아 다음 상태와 동작 하나를 반환한다. 가운데 버튼
또는 손 도구 드래그는 화면 좌표 차이만큼 이동하고, 스크롤은 포인터 위치를 고정해
확대한다. 마우스·펜·지우개는 브러시 시작·이동·종료·취소를 반환하며 다른 장치의
중간 이벤트는 무시한다. 마우스 압력은 1이고 펜 압력과 지우개 여부는 보존한다.
레이어 선택이 사라지면 진행 중인 스트로크를 취소한다. 입력과 뷰포트가 유효하지
않으면 오류만 반환하고 호출자가 보유한 상태는 변경되지 않는다. 스트로크 적용과
뷰포트 게시, 동시 접근 및 실행 순서는 호출자 책임이다.

뷰포트 계획기는 초기화, 지정 거리 이동, 지정 지점을 고정한 확대와 문서 영역의
화면 맞춤을 별도 상태 변경 없이 계산한다. 화면 맞춤은 문서 원점과 회전·반전을
고려하여 영역의 네 모서리를 감싸고 주어진 확대 한도를 적용한다. 결과를 실제 뷰에
적용하는 책임은 호출자에게 있다.

`CanvasNativeViewSource`는 iiGUI 편집 캔버스를 LVUI `NativeView`에 연결하며,
문서·렌더링·편집은 전달받은 콜백을 통해 외부가 소유한다. 마운트 결과는 명시적으로
전달한 `CanvasViewMount` 데이터에 기록된다. 해당 핸들은 iiGUI 소유 스레드에서만
사용하고 뷰가 제거되면 닫힌 상태가 된다. LVUI 뷰와 뷰모델은 해당 소스를 입력받는다.
이름·설명·역할 등의 접근성 의미는 호출자가 제공하며 iiGUI 루트에 전달된다.

타일 캐시는 호출자가 소유하며 리비전, 변경 영역, 새 렌더 타일과 메모리 한계를
명시적으로 전달해 갱신한다. 변경 영역과 겹치는 타일은 통째로 무효화하므로 호출자는
해당 타일 전체를 다시 렌더링해야 한다. 나머지 불변 iiGUI 이미지는 재사용한다.
`CanvasDirtyTilePlanner`는 문서 좌표의 변경 영역과 겹치는 캐시 타일을 모두 찾아
기존 픽셀 크기를 유지하는 전체 타일 렌더 요청을 반환한다. 레이어 좌표를 문서
좌표로 바꾸거나 캐시에 없는 가시 영역을 추가하는 일은 호출자가 담당한다.
오래된 리비전의 비동기 결과는 거부하며 타일 및 픽셀 한계를
초과하면 오래된 항목부터 제거한다. 변경 영역을 누락하지 않는 책임은 호출자에게
있다. 평행 이동·확대 상태에서는 이 이미지들을 iiGUI에 개별 그리기 항목으로 전달할
수 있다. 회전이나 반전에서는 이 타일 표시기가 오류를 반환하므로 호출자는 기존
프레임 표시 경로를 사용해야 한다. 이는 타일 재렌더링 범위와 GPU 업로드 범위가
항상 같다는 보장은 아니다. 타일 표시의 이미지 샘플링은 iiGUI 렌더러 정책을 따르며,
호출자가 정확한 최근접 보간을 지정해야 할 때는 프레임 표시 경로를 사용할 수 있다.

GUI 어댑터와 Python 브리지를 함께 빌드하면 `translate_canvas_input`,
`route_canvas_input`, `present_canvas_frame`으로 동일한 C++ 변환을 호출할 수 있다. Python 호출자는
입력 장치 이벤트와 픽셀 배열을 제공하고 반환된 값과 RGBA 바이트를 소유한다.
GUI 브리지는 별도 라이브러리이므로 기존 헤드리스 Python 브리지는 GUI 런타임을
필요로 하지 않는다. 호출자는 GUI 라이브러리 경로를 `library` 인자로 명시해야 한다.

LVUI는 앱이 제공한 `NativeViewSource`를 `NativeView`에 연결한다. 이 변환기는
레거시 캔버스의 파일 연결, 레이어 선택, 브러시 동작, 타일 캐시, 접근성 또는
실제 장치 검증이 자동으로 완료되었다는 뜻이 아니다. 현재 화면 출력 크기는 iiGUI가
질의한 논리 픽셀 기준이며 별도의 물리 픽셀 배율은 이 인터페이스에서 받지 않는다.
