# 네이티브 PNG 텍스트 메타데이터 계약

네이티브 비트맵 경로는 PNG의 `tEXt`, `zTXt`, `iTXt` 텍스트를 UTF-8
`MediaTextEntry`로 제공하고, 내보낼 때 UTF-8 값을 `iTXt`로 기록한다.
생성 프롬프트의 줄바꿈과 비 ASCII 문자를 정규화하지 않는다. 키는 PNG 규격의
1~79 Latin-1 바이트이며 공백과 제어 문자에 관한 PNG 제약을 따른다.
중복 키와 유효하지 않은 텍스트는 내보내기 전에 거부한다.

가져오기는 모든 청크의 길이와 CRC, IHDR·IDAT·IEND 및 최종 바이트를 확인한다.
압축 텍스트의 해제 결과와 전체 텍스트 용량은 호출자가 제공한 `maxDecodedBytes`
한도를 넘지 않는다. 오류가 발생하면 부분 메타데이터나 픽셀을 반환하지 않는다.
키가 반복되는 외부 PNG는 뒤에 나온 값을 사용한다. 다른 형식의 텍스트는
유지 여부를 보장하지 않으므로 내보내기에서 경고한다.

이 계약은 PNG 텍스트 보존에 한정된다. 다른 레거시 이미지 형식과 SVG/PDF,
비디오 및 화면·입력의 Qt 대체 완료를 의미하지 않는다.
