# 이미지와 캔버스 연산 명세

상태: 구현 중이다. 저장·렌더링·이력과 각 변환의 범위는 아래 계약을 따른다.

현재 구현은 아래 공통 경로를 제공하지만, 픽셀 교체 방식과 회전의 일부 조합은
아직 지원하지 않는다. 지원하지 않는 경우 변경 없이 오류를 반환한다.

## 공통 계약

계획 객체는 입력 문서와 버퍼를 변경하지 않는 값으로 결과를 반환한다. 외부 제어기는
의존 데이터의 수명과 실행 순서를 관리하고, 문서에 적용할 때 전체 변경을 하나의
Undo/Redo로 기록한다. 잘못된 입력, 잠금, 리비전 충돌, 지원하지 않는 표현, 메모리
또는 이력 예산 초과는 원본 문서와 이력을 변경하지 않는다.

## 문서 크기와 회전

`DocumentResamplingPlan`은 지정한 해상도로 문서 전체를 재표본화한다. 래스터,
타임라인 프레임, 마스크와 아트보드에 변환이 적용되며 벡터는 편집 가능해야 한다.
원본 래스터를 새 픽셀로 교체하는 방식과 원본을 보존하고 렌더링 시 표본화하는
방식을 모두 지원해야 한다.
현재 원본 보존 방식은 레이어 변환과 선택 채널을 조정한다. 픽셀 교체 방식은
래스터·비디오 프레임의 출력 크기를 가장 가까운 양의 정수로 정하고 최근접
표본화한다. 각 자산의 실제 크기에 따라 좌표를 보정하며 이전·이후 자산을
하나의 이력 항목으로 보관한다. 청크 래스터는 음수 좌표와 캔버스 바깥의 원본을
포함해 희소 청크로 재표본화한다. 하나의 동적 레이어에서 프레임별 실제 크기 비율이
다른 경우와 연결 캔버스, 패턴 채우기와 공간·위치 의존 래스터 효과 필터는
아직 픽셀 교체를 지원하지 않는다. 포즈·직선 제어 벡터와 비공간 임베딩은 원본을
편집 가능하게 보존하고 레이어 변환을 적용한다. 비활성 필터와 좌표에 무관한 색상
조정, 반전, 회색조, 솔라라이즈, 디헤이즈 필터는 유지하며 활성 디졸브 필터는
픽셀 교체를 거부한다.
깊이·선화·에지·스크리블·노멀·셔플·타일·참조 맵의 조밀 샘플도 최근접 표본화하고
원래 자료형과 편집 가능성을 보존한다.
비등방 스케일에서 페더가 있는 래스터 마스크도 오류를 반환한다.
`CanvasResizePlan`은 콘텐츠를 다시 표본화하지 않고 캔버스 영역을 변경한다.
`ImageRotationPlan`은 전체 문서 요소를 임의 각도로 회전한다. 기울어진 아트보드
경계도 편집 가능하게 저장한다.
현재 회전은 원본 픽셀을 보존하여 렌더링할 때 표본화하며, 물리 픽셀 종횡비를
고려해 캔버스를 확장한다. 비활성 스타일, 불투명도 0인 스타일과 색상 오버레이는
그대로 보존한다. 그 밖의 활성 레이어 스타일이나 디졸브 혼합을 사용하는 문서는
회전과 리샘플을 거부한다.
기울어진 아트보드는 로컬 사각형과 문서 좌표로 가는 가역 아핀 변환을 저장한다.
축 정렬 영역은 그 사각형을 포함하는 정수 경계이며 레이어, 마스크, 배경은 실제
변환된 경계에 맞춰 합성한다. 기존 아트보드는 로컬 원점의 평행 이동으로 해석한다.

## 크롭과 경계

`CanvasCropTransaction`은 캔버스 영역을 줄이되 잘린 바깥 원본 콘텐츠를 보존한다.
`TransparentBoundsScanner`는 입력 픽셀의 알파를 검사하고 비어 있는 결과를 명시한다.
`CanvasContentBoundsQuery`는 보이는 합성과 숨겨진 레이어·캔버스 밖 콘텐츠를
포함하는 범위 중 하나를 명시적으로 선택할 수 있어야 한다.
숨겨진·캔버스 밖 콘텐츠를 조사하는 경우에는 유한한 월드 좌표 검색 영역을
호출자가 지정해야 하며, 작업 픽셀 예산을 초과하면 오류를 반환한다.

## 복제와 픽셀 종횡비

`DocumentCloneTransaction`은 문서의 독립된 복사본을 반환한다. 복제본은 저작자·생성·게시 메타데이터를 보존하며
원본의 Undo/Redo 이력과 활성 편집자 세션은 복제하지 않는다. `DocumentPixelAspectRatio`는 양의
유리수로 저장하며 표시와 내보내기에서 픽셀 종횡비를 반영한다.
타임라인 교환은 원본 유리수를 `source.iisc`에 보존하고 출력 PNG와 XML의 가로
해상도를 정사각 픽셀 기준으로 변환한다. 변환된 해상도에도 출력 제한을 적용한다.
PDF는 페이지의 물리적 너비와 페이지 좌표 변환에 픽셀 종횡비를 반영한다.
