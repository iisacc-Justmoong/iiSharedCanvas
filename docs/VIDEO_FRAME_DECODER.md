# 주입형 비디오 프레임 디코더

`Video/VideoFrameDecoder.h`의 `VideoFrameDecoder`는 압축 바이트를 디코딩하는
애플리케이션 제공 인터페이스이다. `decodeVideoAsset()`은 독립적인 `VideoAsset`을,
`decodeVideoDocument()`는 각 프레임을 키프레임으로 갖는 동적 비트맵 문서를
반환한다. 코덱과 파일 접근을 캔버스 모듈이 직접 선택하거나 소유하지 않는다.
예를 들어 앱은 iiVisualCodec의 메모리 코덱과 iiFileProvider를 별도로 조합할 수 있다.

`VideoDecodeRequest`는 압축 바이트·픽셀·총 디코딩 바이트·프레임 한도,
선택할 첫 프레임과 개수, 선택적인 프레임 속도와 취소 함수를 전달한다. 디코더는
호출 스레드에서 실행되며, 반환 전에 같은 요청의 한도와 취소를 지켜야 한다.
외부 디코더 내부의 임시 할당이나 실행 시간을 캔버스가 강제로 제한하지는 못한다.
취소 함수는 호출자와 디코더에서 동기적으로 부를 수 있으므로 앱이 안전한 수명과
스레드 정책을 정한다.

정상 응답은 표시 방향과 정사각 픽셀로 정규화된 동일한 크기의 직선 알파 ARGB
프레임, 양의 고정 프레임 속도와 요청된 프레임 구간을 포함해야 한다. 캔버스는
바이트 입력, UTF-8 식별자, 반환된 프레임 개수·크기·픽셀 수·총량과 요청 속도를
검사하고 불완전한 결과를 반환하지 않는다. 요청 전후의 취소는 `Cancelled`,
잘못된 응답은 `InvalidData`, 자원 초과는 `LimitExceeded`로 보고한다. 디코더의
오류와 경고는 전달하며, 제외한 오디오 스트림이 있으면 별도 경고를 추가한다.
디코딩된 픽셀 바이트와 별도로 입력 식별자 및 프레임별 생성 식별자의 길이도
같은 `maxDecodedBytes`를 기준으로 제한한다. 이 값은 디코더의 임시 버퍼나 객체
및 할당자 오버헤드를 포함한 프로세스 전체 메모리 상한은 아니다.

이 경계는 코덱을 내장하지 않고 파일을 읽거나 게시하지 않는다. 회전·샘플 종횡비,
가변 프레임 속도 재샘플링, 오디오와 컨테이너 지원은 앱이 제공한 디코더의 계약에
달려 있다. 기존 Qt 비디오 가져오기·내보내기와 같은 전체 지원 범위를 제공한다는
뜻이 아니다. `NativeVideoFrameDecoderTest`는 가짜 디코더를 주입해 프레임 보존,
문서 렌더링, 한도, 오류와 취소를 검사한다.

`example/VisualCodecVideoDecoder.*`는 앱이 캔버스와 iiVisualCodec 0.4.2를
조합하는 제한된 예시이다. 표시 행렬이 항등이거나 평행이동·반전·크기 변경이
없는 정확한 90·180·270도 회전이고, 회전 태그가 없거나 0이며, 픽셀이 정사각형이고
타임스탬프가 일정한 단안 평면 영상을 지원한다. 90도 단위 회전은 디코딩된 픽셀을
보간 없이 재배열하며 크기와 함께 정규화 경고를 반환한다. 미지정 샘플 종횡비는
정사각형으로 간주하고 경고한다. 다른 표시 행렬이나 회전 태그·비정사각 픽셀·공간
영상, 대체 타임스탬프와 가변 속도 또는 요청한 다른 속도는 변환 없이 거부한다.
iiVisualCodec이 디코딩된 프레임에 표시 행렬을 보고하면 스트림 행렬과 비교해
다르거나 잘린 경우 전체 가져오기를 거부한다. 백엔드가 공개하지 않은 표시
메타데이터까지 이 검사가 증명하지는 않는다.
iiVisualCodec이 전체 영상을 메모리로 디코딩한 후 요청 구간을 선택하므로, 선택한
구간이 작더라도 원본 전체가 프레임·디코딩 한도에 들어야 한다. 변환 중 원본 RGBA와
새 ARGB 프레임을 동시에 보유할 수 있다. 누락된 프레임 지속 시간은 한 프레임으로
가정하고 경고한다. FFmpeg가 내부적으로 추정한 타임스탬프의 원본 여부는 이 예시가
증명하지 못한다. 별도 설치 소비자 테스트는 실제 iiVisualCodec FFV1 프레임,
구간 선택, 90도 단위 표시 행렬의 모든 픽셀과 반전 행렬의 거부를 검사한다. 이 검사는
`tests/native-video-consumer`를 `build/` 아래에 별도 구성하고 두 SDK의 스테이징된
CMake 패키지를 지정하여 실행한다.
