# 주입형 비디오 프레임 인코더

`Video/VideoFrameEncoder.h`의 `VideoFrameEncoder`는 애플리케이션이 제공하는
비디오 전용 인코더 인터페이스이다. `encodeVideoFrames()`는 문서의 전체 보기
영역을 지정한 첫 프레임부터 마지막 프레임까지 포함하여 렌더하고, 순서대로
정렬된 직선 알파 ARGB 프레임과 문서의 정확한 유리수 속도를 인코더에 전달한다.
결과는 메모리 바이트이며 저장 경로나 파일 게시 정책은 호출자가 정한다.
`VideoEncodeFrame`의 픽셀 배열은 동기 인코더 호출이 끝날 때까지만 유효한
표준 C++ 읽기 전용 뷰이므로 인코더는 이를 비동기로 보관해서는 안 된다.

프레임 수, 프레임당 픽셀 수, 전체 렌더 픽셀 바이트와 출력 바이트에는 각각
`MediaLimits`가 적용된다. 잘못된 문서·프레임 범위는 인코더 호출 전에 거부한다.
인코더의 오류나 취소가 발생하면 부분 바이트를 반환하지 않으며, 정상 응답의 빈
결과와 한도를 넘은 결과도 거부한다. 인코더의 경고는 유지한다. 문서에 오디오
트랙이 있으면 비디오 전용 출력에 오디오가 포함되지 않는다는 경고를 추가한다.
트랙이 비어 있거나 음소거되어도 보수적으로 경고한다.

선택한 프레임을 모두 메모리에 보유한 후 인코더를 호출한다. 이 한도는 결과
프레임 픽셀에 적용되며 문서 자체, 렌더러의 임시 버퍼, 객체·할당자 오버헤드,
애플리케이션 인코더 내부 할당의 프로세스 전체 상한은 아니다. 호출 중 문서를
변경하지 않아야 한다. 취소 함수는 호출 스레드에서 동기적으로 렌더 전후와 인코더
전후에 호출되며 인코더도 같은 스레드에서 호출할 수 있다. 인코더 내부 작업을
캔버스가 강제로 중단할 수는 없다.

`example/VisualCodecVideoEncoder.*`는 앱이 캔버스와 iiVisualCodec 0.4.2의
메모리 비디오 코덱을 별도로 조합하는 예시이다. 기본값은 Matroska/FFV1이며
프레임과 알파를 보존한다. 앱은 iiVisualCodec의 다른 컨테이너와 코덱을 선택할
수 있지만 백엔드에서 실제로 지원하는 조합만 성공한다. FFV1 외 코덱은 알파를
불투명 매트에 합성하고 색상 충실도 감소 가능성을 경고한다. 사각 픽셀의 평면
단안 영상만 다루며, 속도를 iiVisualCodec의 정수 유리수 범위로 표현할 수 없으면
거부한다. 선택 범위는 결과 시간 0에서 시작한다. iiVisualCodec은 현재 모든 RGBA
프레임과 출력 컨테이너를 메모리에 보유하므로 ARGB 렌더 결과와 별도로 RGBA 복사본
및 코덱 내부 버퍼가 필요하다. 취소는 프레임 변환 전후와 인코더 호출 전후에만
적용되며 진행 중인 iiVisualCodec 인코딩 호출을 중단하지 않는다.

`NativeVideoFrameEncoderTest`는 가짜 인코더로 프레임 순서와 속도, 한도, 오류,
부분 출력 거부 및 취소를 검사한다. `tests/native-video-consumer`는 별도로 설치
스테이징한 두 SDK를 조합하여 실제 FFV1 왕복의 색상·알파와 불투명 코덱의 매트
및 경고를 검사한다. 서로 다른 앱 소유 인코더와 디코더로 정수·분수 프레임 속도
영상의 왕복도 검사한다. 이 예시는 레거시 Qt 비디오 내보내기의 모든 코덱·형식이나
스트리밍 출력과 오디오 믹싱을 지원한다는 의미가 아니다.
