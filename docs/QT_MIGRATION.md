# Qt 제거 진행 상태

이 문서는 기존 기능을 제거하지 않고 iiSharedCanvas에서 Qt를 없애기 위한 현재
경계와 남은 작업을 설명한다. `IISHAREDCANVAS_BUILD_QT_API=OFF`로 구성한
`iiSharedCanvas::Native`는 Qt를 찾지 않고 빌드할 수 있지만, 저장소 전체가 Qt를
제거했다는 의미는 아니다. 기본 설정은 여전히 Qt API를 켜며 기존 Qt 기반 소스와
테스트를 포함한다. 기본값을 바꾸거나 기존 구현을 삭제하기 전에는 대체 기능과
기존 소비자의 이전 경로를 검증해야 한다.

| 영역 | 현재 네이티브 경로 | 남은 차이 |
| --- | --- | --- |
| 문서와 작업 파일 | 캔버스 모델·편집·렌더링·직렬화, SQLite 작업 파일, 업그레이드 및 CLI | 직접 SDK 연결을 애플리케이션이 제공하는 독립 포트로 이전 |
| 비트맵과 레이어 문서 | iiImageCodec 기반 비트맵 코덱과 제한된 PSD/OpenRaster 가져오기·PSD 내보내기 | 기존 Qt/확장 이미지 형식·메타데이터·다중 이미지 범위와 차이를 비교하고 명시적으로 처리 |
| SVG/PDF | 편집 가능한 네이티브 경로의 SVG/SVGZ 및 PDF 내보내기, 자체 SDK 조합 예시의 SVG/SVGZ 왕복과 제한적 SVG 래스터화 | 일반 SVG/SVGZ의 편집 가능한 가져오기와 더 넓은 SVG 및 PDF 페이지 래스터화 |
| 비디오 | 주입형 프레임 디코더·인코더, iiVisualCodec을 조합한 앱 예시와 정규 90도 단위 스트림 표시 회전, 불일치 프레임 행렬 거부 | 프레임별 표시 행렬 정규화, 다른 표시 행렬·회전 태그·비정사각 픽셀·가변 속도 재샘플링, 더 넓은 코덱 범위, 스트리밍 및 오디오 처리 |
| 타임라인 교환 | FCP XML/FCPXML, PNG/WAV, 매니페스트와 원본 스냅샷을 새 디렉터리에 게시 | 레거시 경로와 지원 기능·손실 경고·오류 조건을 계속 비교 |
| 표시와 입력 | 독립적인 프레임 렌더링, 편집·히스토리, 앱 제공 실행기를 쓰는 비동기 렌더 큐와 iiGUI 이미지 변환 예시 | Qt Quick `CanvasItem`/`BitmapItem`에 대응하는 iiGUI 위젯 연결·입력·장치 검증과 소비자 이전 |

비디오 예시는 입력 전체를 디코딩하거나 출력 프레임 전체를 메모리에 보유한다.
정규 90도 단위 표시 회전은 픽셀 재배열로 처리하고 다른 표시 변환·비정사각 픽셀·
가변 속도 입력은 현재 거부하며, 출력에서 오디오를 생략하면 경고한다. 자세한 계약은 [디코더](VIDEO_FRAME_DECODER.md)와
[인코더](VIDEO_FRAME_ENCODER.md)에 있다. [SVG 예시](XML_SVG_IMPORT.md)의 편집형
가져오기는 자체 내보내기 형식만 읽고, 별도의 비트맵 경로는 제한된 도형과
그라디언트를 지원한다. 일반 SVG 가져오기를 대체했다고 간주하지 않는다.

Qt 비활성 패키지에도 SDK 간 직접 연결이 남아 있다. 현재 네이티브 CMake는
iiPaintEngine, iiFileProvider Native·Compatibility, iiSDKCore Contracts와
iiImageCodec을 직접 찾고 링크하며, LibXml2와 zlib도 직접 연결한다. 일부 공개 문서
모델도 하위 SDK의 타입을 사용한다. 별도 애플리케이션 예시의 SDK 조합과 캔버스 모듈 자체의 직접 연결은
구분해야 한다. 파일 저장 책임은 iiFileProvider에 유지하면서 호출자 제공 인터페이스로
전환하고, 그림 처리·코덱·XML 및 압축도 자체 SDK를 조합하는 교체 가능한 경계로
이전해야 한다. Workspace의
상위 `SDK/docs/SDKIndependence.md`는 현재 참조와 정적 검사 한계를 설명한다.

완료 판정에는 기존과 새 기능의 테스트뿐 아니라 전체 소스·공개 헤더·CMake와
설치 패키지에서 Qt 참조가 없는지 확인해야 한다. Qt 검색을 비활성화한 새 빌드,
독립 설치 소비자, 실제 연결 라이브러리 검사와 각 대상 플랫폼의 실행 검증은
서로 다른 증거다. 스테이징 성공은 `~/.local` 설치나 기존 실행 프로세스 갱신을
뜻하지 않는다. 현재 macOS 테스트의 일부 연결 라이브러리는 빌드에서 지정한
최소 macOS 12보다 높은 macOS 27을 대상으로 하므로 macOS 12 런타임 호환성을
아직 주장할 수 없다. Linux·Windows와 모바일 런타임도 별도로 확인해야 한다.
